# Smart Meter Data Validation System

## Overview
This project processes large smart meter CSV data and validates it against consumer master records using Python and Pandas.

## Problem
Manual verification of meter data against consumer records was time-consuming and error-prone.

## Solution
Automated data matching and validation using Python (Pandas).

## Features
- Data merging using consumer ID
- Validation of records
- Missing data detection
- Output generation in structured format

## Tools Used
- Python
- Pandas

## Output
Final cleaned dataset with validation status (VALID / INVALID)

## Impact
Reduced manual verification effort by ~75%
